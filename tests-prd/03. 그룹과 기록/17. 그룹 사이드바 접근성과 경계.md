# 17. 그룹 사이드바 접근성과 경계

> E2E: `tests/03. 그룹과 기록/17. 그룹 사이드바 접근성과 경계/`

1. Group 명령은 제어 대상과 펼침 상태를 제공한다.
2. 열린 사이드바는 제목에 `Group`을 표시하고 같은 이름의 complementary 랜드마크다.
3. 사이드바 닫기 버튼은 대상 이름을 `Close Group`로 제공한다.
4. 각 그룹 영역 버튼은 고유한 aria-controls로 실제 목록을 가리키고 펼침 상태를 제공한다.
5. Group 메뉴의 All Group 선택 상태는 aria-pressed로 표시한다.
6. 사이드바의 열림과 닫힘 상태를 새로고침 후 복원한다. PC에서 Card 패널이 함께 열려 있어도 URL 패널 복원 때문에 저장된 메뉴 상태를 덮어쓰지 않는다.
