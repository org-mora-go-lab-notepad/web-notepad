# 21. 게시판 자동 목록과 접근

> E2E: `tests/03. 그룹과 기록/21. 게시판 자동 목록과 접근/`

1. role admin URL은 게시판을 자동으로 열거나 관리자 표시·등록·수정·삭제 기능을 활성화하지 않는다. 게시판 API를 사용할 수 없는 초기 환경에서는 시스템 집계 행 없이 3개의 읽기용 mock 그룹만 표시한다.
2. Board는 별도 등록 없이 현재 공유 중인 모든 그룹을 표시하고, 로그인한 사용자의 공유 그룹과 다른 사용자의 그룹을 모두 포함한다.
3. 그룹 이름의 HTML은 글자로 표시하며 목록 API에 노트 본문을 노출하지 않는다.
4. 내가 공유한 그룹 상세는 참여 링크 대신 공유 취소를 제공하고, 확인 후 노트를 보존하며 게시판 공개를 종료한다.
5. 이미 참여한 그룹 상세는 참여 링크 대신 그룹 나가기를 제공하고, 확인 후 내 참여만 해제한다.

6. 내 그룹 Notes 수는 Card의 다섯 상태(Note·To Do·Ready·Doing·Done)에 해당하는 본문이 있는 탭 전체를 합산한다. 에디터에서 닫힌 탭과 한두 글자 본문도 카드와 같이 포함하며 빈 본문은 제외한다. 목록과 상세 Workspace overview는 같은 합계를 표시하고 노트 데이터를 변경하지 않는다.
