# 21. 게시판 자동 목록과 접근

> E2E: `tests/03. 그룹과 기록/21. 게시판 자동 목록과 접근/`

1. role admin URL은 게시판을 자동으로 열거나 관리자 표시·등록·수정·삭제 기능을 활성화하지 않는다. 게시판 API를 사용할 수 없으면 재시도 안내를 표시한다.
2. Board는 로그인 사용자가 소유하거나 참여 중인 공유 그룹을 표시한다. 참여하지 않은 그룹은 목록·API 응답에 포함하지 않고 직접 상세 주소로도 열 수 없다.
3. 그룹 이름의 HTML은 글자로 표시하고 권한 있는 사용자에게만 노트 본문을 제공한다.
4. 내가 공유한 그룹 상세는 참여 링크 대신 공유 취소를 제공하고, 확인 후 노트를 보존하며 게시판 공개를 종료한다.
5. 참여 중인 그룹 상세에서 그룹 나가기를 실행하면 내 참여를 해제하고 내 Board에서 그룹을 제외한다.

6. 내 그룹 Notes 수는 Card의 다섯 상태(To Do·Waiting·In Progress·Done·Closed)에 해당하는 본문이 있는 탭 전체를 합산한다. 에디터에서 닫힌 탭과 한두 글자 본문도 카드와 같이 포함하며 빈 본문은 제외한다. 목록과 상세 Workspace overview는 같은 합계를 표시하고 노트 데이터를 변경하지 않는다.

7. 비로그인 상태에서는 PC·모바일 Menu와 기존에 고정한 푸터에서 Board를 숨긴다.
8. 비로그인 상태에서 Board 목록·상세 URL을 열면 홈으로 이동하고 Board 데이터를 요청하지 않는다.
