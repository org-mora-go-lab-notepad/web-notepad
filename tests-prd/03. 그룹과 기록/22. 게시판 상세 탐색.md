# 22. 게시판 상세 탐색

> E2E: `tests/03. 그룹과 기록/22. 게시판 상세 탐색/`

1. PC 브라우저와 갤럭시 크기 모바일에서 목록과 상세의 뒤로가기는 목록 기준의 동일한 상단 위치·높이·글자 크기·줄 높이, 왼쪽 Chevron 아이콘과 hover 배경을 사용한다. 게시글 상세를 연 뒤 브라우저 기록의 뒤로가기를 실행하면 게시판 목록으로 돌아온다.
2. 공유 그룹 보드 상세는 그룹 소개·작업공간 요약·공유 노트 내용·공동 작업 및 접근 구역으로 구성한다. 작업공간 요약에는 노트 수·참여자 수·최근 변경일을 카드로 표시하고, 공유 노트 내용에는 모든 노트의 제목과 전체 본문을 표시한다. 노트 편집기 높이 조절은 제공하지 않으며, PC와 모바일 상세 편집기 내부 스와이프로 탭을 전환하고 푸터 스와이프는 탭을 전환하지 않는다. `Back`·그룹명·작성자·제목·메타 정보와 설명 글자를 확대해 표시하고 안내·작업 버튼의 확대 크기를 유지한다.
3. 모바일 보드 상세의 편집기를 좌우로 스와이프하면 노트 탭을 순환 이동하고 활성 탭을 노출한다. 이후 첫 터치로 메뉴·대시보드·사용자 진입점이 동작한다. 브라우저 호환 click이 누락돼도 touchend에서 실행하고 중복 click은 재실행하지 않는다.
4. PC 보드 상세의 노트 편집기는 기본 높이를 475.2px로 고정하고 높이 조절 기능을 제공하지 않는다. 탭을 전환해도 편집기 위치·크기와 본문 transform을 바꾸는 애니메이션이 없어 텍스트가 흔들리지 않으며, 모바일에서는 방향별 슬라이드 효과를 유지한다.
5. 보드 상세 노트의 본문이 길어 내부 스크롤이 생기면 편집기 안에서 끝까지 읽을 수 있고, 최하단에서 계속 아래로 스크롤하면 입력을 가두지 않고 상세 페이지의 다음 콘텐츠로 자연스럽게 이동한다.
6. 보드 목록을 아래로 스크롤한 상태에서 그룹을 열어 상세화면으로 진입하면 페이지 스크롤을 항상 최상단으로 초기화한다.

7. 상세의 노트 탭은 메모·나중에·이번주·진행중·완료 다섯 상태 순서로 정렬하고 각 상태 안에서 북마크·제목순을 유지한다. 닫힌 편집기 탭도 본문이 있으면 모든 상태의 노트를 볼 수 있다.
8. 각 탭 헤더의 상단 테두리·활성 강조와 선택 라인의 왼쪽 테두리·줄 번호는 해당 노트의 상태 색상을 사용한다. 선택 라인의 배경은 동일 색상의 20% 강조로 편집기 너비를 채우며, 탭을 전환하면 함께 갱신한다. PC·모바일에서 다섯 상태를 단일 완료 색상으로 통일하지 않고 선택하지 않은 라인의 배경은 유지한다.

9. PC에서도 보드 상세 편집기를 좌우로 드래그하면 다음·이전 노트로 순환한다. 짧거나 수직인 움직임은 탭을 전환하지 않는다.
