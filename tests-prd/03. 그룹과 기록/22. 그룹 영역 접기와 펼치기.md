# 22. 그룹 영역 접기와 펼치기

> E2E: `tests/03. 그룹과 기록/22. 그룹 영역 접기와 펼치기/`

1. 현재 계정의 참여 권한을 확인하는 동안 로딩 상태를 표시하고 저장된 공유 그룹 목록은 먼저 노출하지 않는다. 확인 후 내가 공유한 그룹과 초대받은 그룹은 모두 Shared Group에 표시하고 개인 그룹은 My Group에 표시한다. 공유를 취소한 내 그룹은 My Group으로 돌린다.
2. 영역 우측 화살표 버튼은 키보드와 클릭으로 독립적으로 접고 펼치며 현재 노트를 보존한다.
3. 접기 상태를 사이드바 재진입과 새로고침 뒤에도 유지한다.
4. My Group을 접은 채 새 그룹을 생성하면 펼쳐서 보여주며 시스템 그룹은 하단 Group Option 메뉴에 유지한다.

5. 권한을 확인하지 못한 그룹은 숨기고 Shared Group에서 재시도할 수 있다. 조회가 성공하면 확인된 그룹을 표시한다.

6. My Group과 Shared Group은 사이드바 헤더·하단 Group Option 버튼 행 사이의 남은 높이를 기본 50%씩 차지하며 My Group 제목 위의 중복 경계선을 제거한다. 두 영역 사이의 가로 separator를 마우스·터치 드래그하거나 키보드로 움직여 20~80% 범위에서 높이를 조절하고 새로고침 후 복원한다. PC에서 두 제목을 hover할 때 강조 배경은 위아래만 10% 줄이고 사이드바 좌우를 가득 채우며 클릭 영역은 유지한다.
