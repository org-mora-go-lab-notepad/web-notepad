# 20. 공유 그룹 - 참여와 공유 해제

> E2E: `tests/03. 그룹과 기록/20. 공유 그룹 - 참여와 공유 해제/`

1. 공유 그룹 목록의 그룹 행은 우측 점 세 개 동작 아이콘을 표시한다. 공유 중인 주최자의 동작 메뉴에는 공유하기·공유 취소·그룹 나가기를 표시하지 않으며, 공유 취소는 보드 상세에서 제공한다. PC에서 그룹명을 우클릭하면 `Close All → Pin to footer → Edit` 세 항목을 한 드롭다운에 표시하고 한국어 설정도 같은 순서를 유지한다.
2. 참여자의 PC·모바일 동작 아이콘 메뉴에는 그룹 나가기를 표시하고 공유·공유 취소·삭제는 숨긴다. 모바일에서는 그룹 행을 길게 눌러 같은 동작 메뉴를 열 수도 있다.
3. 그룹 나가기는 자신의 참여만 해제하며 주최자의 노트는 보존하고 내 목록에서 제거한다.
4. 주최자가 공유를 취소하면 원문은 보존하고 다른 참여자·기존 초대 링크·게시판의 접근을 해제한다.
5. 취소한 그룹을 다시 공유하면 새 초대 링크를 발급하고 이전 링크는 계속 거부한다.
6. 나가기·공유 취소·재공유는 로그인과 소유권을 검사하고 다른 출처의 변경 요청은 거부한다.
