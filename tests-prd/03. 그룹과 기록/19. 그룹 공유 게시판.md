# 19. 그룹 공유 게시판

> E2E: `tests/03. 그룹과 기록/19. 그룹 공유 게시판/`

1. 게시판은 별도 /board 페이지에 그룹·공유자·노트 수·참여자 수·최근 변경 테이블을 표시하고 방문자에게 관리 버튼을 노출하지 않는다. 다섯 컬럼은 같은 간격으로 배치하고 헤더 글자색은 대시보드 상태 표시 글자색과 일치시키며, 로딩 Skeleton과 실제 목록의 헤더 위치를 일치시킨다. 헤더 아래의 Skeleton 행 높이는 실제 데이터 행과 같고, 리스트의 그룹 항목은 아이콘 없이 그룹명만 표시한다. 긴 그룹명은 최대 두 줄까지 표시한 뒤 말줄임으로 셀 안에 유지하고 전체 이름을 툴팁으로 제공한다. 공유자는 아이콘과 카카오 이름으로 표시한다.
2. 게시글 상세는 공유자 아이콘·카카오 이름, 공유 그룹의 모든 노트 제목과 본문, 일반 안내와 참여 링크를 제공하고 클릭만으로 그룹을 추가하지 않는다. 상세 에디터의 높이 조절 핸들은 제거하며, PC·모바일 보드의 상세 에디터 스와이프는 노트 탭을 전환하고 푸터 스와이프는 전환하지 않는다.
3. 로그인한 방문자는 게시글 초대를 수락해 실제 공유 그룹에 참여한다.
4. 비로그인 방문자가 초대를 열면 로그인 안내와 원래 공유 링크를 유지한다.
5. 검색은 그룹 이름을 찾고 결과가 없을 때 명확하게 안내한다.
6. 작은 모바일과 라이트 테마에서 목록과 참여 버튼이 화면 안에 표시된다. 고정 뒤로가기 헤더의 하단 경계와 모바일 푸터의 상단 경계에는 대시보드 상태 표시줄과 같은 2px blur 그라데이션을 적용한다.
7. Board 목록은 내 그룹과 공유 그룹을 함께 표시한다.
8. Board 목록에서는 `All Group`, `All My Group`, `All Shared Group`, `All My Ungrouped`, `Ungrouped` 같은 시스템 집계 그룹을 제외하고 실제 My Group과 Shared Group만 표시한다.

9. 긴 그룹명은 PC·모바일에서 최대 두 줄 뒤 말줄임하고 전체 이름은 툴팁으로 제공한다. Group과 Shared by 사이 간격을 10px 넓히며, Shared by의 왼쪽 패딩은 26px로 헤더·Skeleton·실제 행에 동일하게 적용한다.
