# 상태 이동과 드래그 예외

> E2E: `tests/07. 대시보드/06. 상태 이동과 드래그 예외/`

1.  PC에서 카드를 다른 컬럼으로 드래그하면 상태와 탭 색상을 대상 컬럼에 맞게 변경한다.

2.  드래그로 변경한 상태는 브라우저에 저장하고 새로고침 후 복원한다.

3.  짧은 일반 탭의 열린 카드를 Closed으로 옮겨도 편집기에 열린 상태를 유지한다.

4.  고정 탭을 Closed으로 옮기면 확인 팝업 없이 핀 표시 없이 열린 상태와 기존 데이터를 유지하고, 새로고침 후에도 Closed 상태를 복원한다.

5.  대시보드 카드가 아닌 외부 데이터는 강조하거나 상태를 변경하지 않는다.
