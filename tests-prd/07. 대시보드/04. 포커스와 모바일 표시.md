# 포커스와 모바일 표시

> E2E: `tests/07. 대시보드/04. 포커스와 모바일 표시/`

1.  현재 탭 카드는 상태 색상의 12% 배경과 50% 불투명도 1px 테두리로 강조하고 추가 외곽선 없이 접근성 현재 표시를 제공한다. Note·Done 상태의 현재 탭 카드는 탭 자체 색상 대신 해당 상단 상태 색상으로 배경과 테두리를 강조한다.

2.  PC 고정 대시보드에서 다른 카드를 선택하면 편집기 활성 탭과 카드 강조를 함께 옮긴다.

3.  PC 대시보드 헤더는 카드 목록을 스크롤해도 상단에 고정한다. 스크롤 중 상태 표시 아래에는 24px 범위의 2px 배경 블러를 표시하고, 블러 불투명도는 상태 표시와 맞닿은 지점의 100%에서 아래쪽의 0%까지 연속적으로 낮아진다.

4.  모바일 대시보드의 첫 상태 제목과 헤더 사이는 20px 간격으로 표시한다. 스크롤하면 상태 제목을 Dashboard 헤더 바로 아래에 맞닿게 고정하고, Doing·Ready·To Do·Done 영역에 차례로 진입할 때 해당 상태 제목으로 교체해 고정한다.

5.  모바일 대시보드를 위로 스크롤하면 To Do·Ready·Doing 영역에 차례로 진입할 때 해당 상태를 다시 상단에 고정한다.

6.  모바일에서 탭 카드 더블탭으로 연 드롭다운은 Escape 또는 브라우저 뒤로가기로 닫고 기본 카드 화면을 유지한다. 더블탭에서는 단일 탭 편집 바텀시트를 열지 않는다.

> 모바일 카드에는 To Do·Doing·Done 상태 변경 버튼을 표시하지 않는다.
