# 모바일 카드 조작

> E2E: `tests/07. 대시보드/20. 모바일 카드 조작/`

1. 모바일 카드 헤더는 X와 단독 + 버튼을 숨기고 세로 점 옵션 버튼을 오른쪽 끝에 둔다. 옵션 첫 항목은 아이콘과 Add Tab(탭 추가)이며 새 탭의 편집 시트를 열고 닫으면 옵션 버튼으로 포커스를 복원한다.
2. 시트 손잡이를 짧고 빠르게 위아래로 튕기면 25·50·75·100% 중 방향에 맞는 다음 높이로 부드럽게 전환한다. 천천히 끈 경우 가까운 높이에 정착하고 마지막 높이를 저장한다.
3. 손잡이를 아래로 강하게 튕기면 시트만 닫고 편집 내용과 카드 선택을 보존한다. 다시 열면 마지막 정착 높이를 사용하며 닫힘 제스처의 중간 높이를 저장하지 않는다.
4. 모바일 그룹과 카드 푸터는 현재 보이는 화면만 선택 상태로 표시한다. 미선택 아이콘은 기본 윤곽선, 선택 아이콘은 채운 검은색(어두운 테마에서는 대비되는 전경색)을 사용한다. 그룹 헤더는 X를 숨기고 푸터 버튼으로 카드 화면으로 전환할 수 있다.

5. 시트 높이를 조절한 뒤에도 줄 선택·닫기·카드 열기는 첫 터치에 한 번 실행된다. 브라우저의 호환 click이 누락되거나 뒤늦게 도착해도 누락·중복 실행하지 않는다. 카드 더블 탭 메뉴와 드래그는 유지한다.
6. light 테마 바텀시트는 흰색 배경을 사용하고 dark 테마의 배경은 유지한다.

7. 모바일 상태별 펼침·접힘을 그룹별로 현재 브라우저에 저장하고 새로고침·재접속·그룹 재진입 후 복원한다. 공유 그룹의 다른 사용자에게 표시 상태를 전파하지 않으며 PC 컬럼은 항상 펼쳐 표시한다.
