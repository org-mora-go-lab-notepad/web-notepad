# 모바일 카드 조작

> E2E: `tests/07. 대시보드/20. 모바일 카드 조작/`

1. 모바일 카드 헤더는 X와 단독 + 버튼을 숨기고 세로 점 옵션 버튼을 오른쪽 끝에 둔다. 옵션 첫 항목은 아이콘과 Add Tab(탭 추가)이며 새 탭의 편집 시트를 연다.
2. 시트 손잡이를 짧고 빠르게 위아래로 튕기면 25·50·75·100% 중 방향에 맞는 다음 높이로 부드럽게 전환한다. 천천히 끈 경우 가까운 높이에 정착하고 마지막 높이를 저장한다.
3. 손잡이를 아래로 강하게 튕기면 시트만 닫고 편집 내용과 카드 선택을 보존한다. 다시 열면 마지막 정착 높이를 사용하며 닫힘 제스처의 중간 높이를 저장하지 않는다.
4. 모바일 그룹과 카드 푸터는 현재 보이는 화면만 선택 상태로 표시한다. 미선택 아이콘은 기본 윤곽선, 선택 아이콘은 채운 검은색(어두운 테마에서는 대비되는 전경색)을 사용한다. 그룹 헤더는 X를 숨기고 푸터 버튼으로 카드 화면으로 전환할 수 있다.
