# 상태 이름과 빈 표시

> E2E: `tests/07. 대시보드/09. 상태 이름과 빈 표시/`

1.  PC와 모바일에서 Edit Status를 선택하면 적용 대상 그룹명과 다섯 상태의 입력란을 표시한다. 저장한 이름은 현재 그룹의 상태 제목과 메뉴에만 적용하고 새로고침과 그룹 전환 후에도 유지하며 다른 그룹과 탭 색상은 변경하지 않는다. 기본 이름은 언어에 따르고 빈 입력은 기본 이름으로 복원하며 최대 30자까지 입력한다. 이전 전역 설정의 상태 이름은 적용하지 않는다.

2.  이름 편집을 Cancel·Escape·팝업 바깥 클릭으로 취소하면 저장하지 않고 대시보드를 유지하며 세로 점 버튼으로 포커스를 돌려준다.

3.  All Group에서도 Edit Status로 상태 이름을 편집하고 별도 저장하며 새로고침 후 복원한다. 개별 그룹의 상태 이름은 변경하지 않는다.

4.  모바일에서 Note·To Do·Doing·Done가 비어 있으면 모두 Doing 참고 이미지와 같은 둥근 점선 테두리와 중앙 정렬의 영역을 표시한다. 빈 영역의 좌우 끝은 상태 표시줄의 좌우 끝과 일치하고 위아래 여백은 12px이다. 영어와 한국어 모두 문구는 `None`을 사용하고 Add 버튼은 표시하지 않는다. PC에서는 빈 영역을 표시하지 않는다.
5.  공유 그룹에서 Edit Status로 바꾼 이름을 협업자에게 동기화하고 재접속 후 복원한다. 사용자 지정 이름은 Note·To Do·Ready·Doing·Done의 상태 위치를 변경하지 않으며 참여자도 같은 상태 이름을 편집할 수 있다.

> 사용자 지정 상태 이름과 상태 편집 폼의 기본 순서는 유지한다. 실제 카드 목록은 PC 기본 순서, 모바일 Doing·Ready·To Do·Done·Note 순서로 표시한다.
