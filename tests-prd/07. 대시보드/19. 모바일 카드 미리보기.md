# 모바일 카드 미리보기

> E2E: `tests/07. 대시보드/19. 모바일 카드 미리보기/`

1. 모바일 카드 단일 터치는 Card 패널과 메인 편집기의 활성 탭·본문을 유지한 채 읽기 전용 바텀시트에서 탭 전체 본문을 표시한다. 줄바꿈과 공백을 보존하고 에디터를 포커스하거나 키보드를 열지 않는다.
2. 에디터에서 닫힌 탭도 전체 본문과 북마크 표시를 읽을 수 있다. 미리보기와 닫기는 탭을 다시 열거나 본문·탭 목록을 변경하지 않으며 HTML 문자는 텍스트로 표시한다.
3. 긴 본문은 뷰포트 아래에 붙은 시트 내부에서 마지막 줄까지 스크롤한다. 바깥 카드 목록 스크롤은 움직이지 않는다.
4. 닫기 버튼은 시트만 닫고 이전 Card 목록 스크롤과 누른 카드의 포커스를 복원한다. 다음 카드 선택도 한 번의 터치로 동작한다.
5. 모바일 브라우저 뒤로가기는 먼저 시트만 닫아 Card 패널에 남고 다음 뒤로가기에서 패널을 닫는다. 미리보기 자체는 URL과 메인 탭 선택을 바꾸지 않는다.
6. 시트 위쪽 바깥 배경을 터치하면 시트만 닫는다. 이어 다른 카드를 한 번 터치하면 그 본문을 새로 표시한다.
7. 키보드 Tab 포커스는 시트의 닫기 버튼과 본문 스크롤 안에서 순환한다. Escape는 시트만 닫고 카드 포커스를 복원한다.
8. PC 너비로 전환하면 미리보기를 정리하고 본문 스크롤 잠금을 해제한다. 모바일로 돌아와도 지난 시트를 자동으로 다시 열지 않는다.
