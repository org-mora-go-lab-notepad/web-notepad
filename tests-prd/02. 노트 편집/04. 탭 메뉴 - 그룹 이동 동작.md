# 04. 탭 메뉴 - 그룹 이동 동작

> E2E: `tests/02. 노트 편집/04. 탭 메뉴 - 그룹 이동 동작/`

1.  `Move Group`에서 대상 그룹을 선택하면 해당 탭을 옮기며 ID, 내용, 저장 기준 내용, 색상, 이전 버전의 고정 데이터(화면에는 표시하지 않음), 줄 선택과 연결 북마크를 유지한다.

2.  그룹 이동 후 현재 그룹 화면은 유지하고 대상 그룹에서는 옮긴 탭을 왼쪽 패널의 활성 탭으로 지정한다.

3.  원래 그룹의 마지막 탭을 이동하면 빈 탭을 새로 만든다.

4.  오른쪽 패널의 탭을 `Move Group`으로 옮겨 비워지면 분할을 해제하고 남은 탭을 왼쪽 활성 탭으로 지정한다.

5.  분할 패널의 탭을 이동해도 대상 그룹의 기존 오른쪽 패널과 나머지 탭은 유지한다.

6.  닫힌 탭 기록만 남은 그룹에서 마지막 열린 탭을 이동하면 기존 닫힌 탭·본문·북마크를 보존하면서 새 빈 탭을 추가해 `NOTEPAD_` 로딩 화면에 머물지 않는다. 다른 개인 그룹의 열린 탭과 닫힌 탭을 모두 DB에 유지하며, 2자 본문 탭도 대상 그룹에 저장하고 재접속 후 같은 ID로 복원한다.
