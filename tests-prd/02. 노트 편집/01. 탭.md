# 01. 탭

> E2E: `tests/02. 노트 편집/01. 탭/`

1.  마지막 열린 탭을 닫으면 자동으로 빈 탭을 만들지 않고 메인 에디터 상단에 새 탭 `+` 버튼만 표시한다. 내용이 있는 닫힌 탭의 원문은 보존하며 새로고침 후에도 빈 편집 상태를 유지한다.

2.  에디터에서 생성한 새 탭은 To Do를 기본 상태로 사용한다. 현재 탭의 Note·Doing·Closed 상태를 이어받지 않으며 사용자 지정 색상 순서에서도 첫 번째 색상으로 생성한다. 원하는 기존 탭을 다시 선택할 수 있다.

3.  탭 제목에서 드래그를 시작해 탭 순서를 바꿀 수 있다.

4.  내용이 저장 기준 내용과 다르면 탭에 변경 표시를 보여준다.

5.  탭 제목은 내용의 첫 번째 비어 있지 않은 줄을 앞뒤 공백 제거 후 최대 28자로 표시한다.

6.  탭 제목을 최대 28개의 표시 문자로 제한하며 이모지와 결합 문자를 중간에서 잘라 깨뜨리지 않는다.

7.  최초 진입 또는 비어 있는 그룹에는 탭·본문·줄 번호를 만들지 않고 상단 `+`만 표시한다. 사용자가 `+` 또는 모든 탭이 닫힌 빈 에디터 영역을 명시적으로 클릭·터치해야 새 탭을 생성한다.

8.  PC에서 현재 그룹의 모든 탭이 닫혔을 때 빈 에디터 영역을 클릭하면 + 버튼과 같은 경로로 새 탭 하나를 생성한다. 빠른 두 번 클릭도 추가 빈 탭을 중복 생성하지 않으며 기존 닫힌 탭 원문을 보존한다.
9.  모바일 카드 화면의 + 버튼을 누르면 새 탭 하나를 생성한다. 생성 후 본문 입력과 후속 터치는 탭을 추가하지 않는다.
10. 분할 에디터를 포함해 탭이 하나라도 열려 있으면 빈 본문의 탭을 클릭하더라도 새 탭을 만들지 않는다. PC 분할 편집기에서 기존 본문과 탭 목록을 유지한다. 모바일은 바텀시트 편집기를 사용한다.
