# 36. 푸터 더보기

> E2E: `tests/05. 화면과 설정/36. 푸터 더보기/`

1. PC에서는 Settings를 열어도 그룹 사이드바를 유지하고 새로고침 후 함께 복원한다. 모바일에서는 Settings를 열면 그룹 사이드바를 닫고 새로고침해도 설정 화면과 닫힌 사이드바를 복원한다. PC에서 사이드바를 직접 닫은 뒤 새로고침해도 닫힌 상태를 유지한다.
2. 보드의 푸터 더보기에서 Search를 한 번 선택하면 메인 검색 팝업으로 이동하며 검색 입력을 사용할 수 있다.
3. 마이페이지의 푸터 더보기에서 Guide를 선택하면 메인 사용 가이드를 열고 Escape로 닫을 수 있다.
4. 모바일 푸터 스와이프 직후 더보기와 그 하위 명령은 각각 한 번의 터치로 동작하고, 팝업 터치가 푸터 스와이프로 해석되지 않는다.

5. 초기 클라이언트 화면이 준비되기 전에는 Menu 버튼을 비활성화하고 준비 후 첫 클릭으로 메뉴를 연다. 푸터 Menu 드롭다운 맨 위에 있는 Theme 스위치는 Home 키로도 접근하며 Settings 화면을 열지 않고 밝은·어두운 테마를 즉시 전환한다. 메뉴를 유지하고 새로고침·보드·마이페이지에서도 같은 테마를 복원한다. 마우스·터치·키보드 Space로 조작할 수 있다.

6. 모바일 푸터는 그룹·카드·사용자·Menu 네 영역을 동일 너비로 배치해 중심 간격을 맞춘다. 오른쪽은 28.8px 가로 세 줄 Menu 아이콘 아래 영어 Menu·한국어 메뉴를 다른 푸터 항목과 같은 글자 크기·줄 높이·중앙 정렬로 표시한다. PC도 오른쪽에 같은 메뉴 아이콘을 사용하지만 텍스트는 숨긴다. 왼쪽 그룹 진입점은 PC·모바일 모두 Layers 아이콘을 사용하며 320~512px 폭과 로그인 전후에도 정렬을 유지한다.
