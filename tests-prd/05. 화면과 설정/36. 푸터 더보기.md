# 36. 푸터 더보기

> E2E: `tests/05. 화면과 설정/36. 푸터 더보기/`

1. PC·모바일에서 더보기의 Settings를 열어도 메뉴 열림 상태를 유지한다. 새로고침 후 설정과 메뉴를 함께 복원하며 메뉴를 직접 닫은 뒤 새로고침하면 닫힌 상태를 유지한다.
2. 보드의 푸터 더보기에서 Search를 한 번 선택하면 메인 검색 팝업으로 이동하며 검색 입력을 사용할 수 있다.
3. 마이페이지의 푸터 더보기에서 Guide를 선택하면 메인 사용 가이드를 열고 Escape로 닫을 수 있다.
4. 모바일 푸터 스와이프 직후 더보기와 그 하위 명령은 각각 한 번의 터치로 동작하고, 팝업 터치가 푸터 스와이프로 해석되지 않는다.

5. 푸터 더보기의 Theme 스위치는 Settings 화면을 열지 않고 밝은·어두운 테마를 즉시 전환한다. 메뉴를 유지하고 새로고침·보드·마이페이지에서도 같은 테마를 복원한다. 마우스·터치·키보드 Space로 조작할 수 있다.
