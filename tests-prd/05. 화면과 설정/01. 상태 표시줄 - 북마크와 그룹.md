# 01. 상태 표시줄 - 북마크와 그룹

> E2E: `tests/05. 화면과 설정/01. 상태 표시줄 - 북마크와 그룹/`

1. 그룹 사이드바 상단 제목은 Group(한국어 그룹)이며, 하단에는 기존 그룹 아이콘과 Group Option(한국어 그룹 옵션) 버튼 하나를 가로 전체에 배치한다. PC 행 높이 48px·모바일 50.6px를 유지하고 시스템 그룹과 그룹 추가 입력을 제공한다. 푸터 우측은 가로 세 줄 메뉴 아이콘을 사용하며 PC는 아이콘만, 모바일은 아이콘 아래 Menu(한국어 메뉴)를 표시한다. 오른쪽 메뉴는 맨 위 Theme와 Guide·Search·Bookmark·Settings·Board 순서의 명령을 제공하며 Escape로 닫으면 트리거로 포커스를 돌린다.

2. 푸터 Menu의 Bookmark 명령은 그룹 사이드바를 유지하고 북마크 팝업을 연다. Menu 버튼에는 북마크 개수·상태 표시를 포함하지 않는다.

3. PC 푸터 왼쪽에는 현재 그룹 이름을 명령 텍스트보다 2px 크게 표시하고 클릭으로 그룹 사이드바를 토글한다. 중앙 그룹 진입점은 Layers 그룹 아이콘과 Group(한국어 그룹) 라벨을 표시한다. 모바일은 별도 왼쪽 그룹명을 숨기고 첫 진입점에 Layers 아이콘 아래 Group(한국어 그룹)을 고정 표시한다. 선택된 그룹명은 카드 화면 상단에 표시한다.

4. Group 메뉴의 All Group·All My Group·All Shared Group·Ungrouped 항목에는 그룹 동작 아이콘을 표시하지 않는다.

5. PC에서 일반 그룹의 우측 동작 아이콘으로 연 드롭다운에는 Close All·공유·수정·삭제만 표시하고 Bookmark를 표시하지 않으며 그룹 선택을 바꾸지 않는다. 그룹명 우클릭은 `Pin to footer` 한 항목만 표시한다. 그룹 드롭다운은 최소 216px로 넓혀 텍스트가 잘리지 않으며 우측 점 세 개의 Edit로 기존 그룹명 수정 입력을 연다.

6. 오늘 생성되거나 변경된 그룹이 있으면 Group 아이콘에 Bookmark와 같은 붉은 점을 표시하고, 오래된 그룹만 있으면 표시하지 않는다.
