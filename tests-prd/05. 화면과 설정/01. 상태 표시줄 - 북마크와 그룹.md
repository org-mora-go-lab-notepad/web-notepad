# 01. 상태 표시줄 - 북마크와 그룹

> E2E: `tests/05. 화면과 설정/01. 상태 표시줄 - 북마크와 그룹/`

1. 그룹 사이드바 하단에는 `Default Group`(한국어 `기본 그룹`) 버튼 하나를 가로 전체에 배치한다. PC 행 높이 48px, 모바일 50.6px를 유지한다. 기본 그룹 드롭다운은 All Group·All My Group·All Shared Group·Ungrouped와 그룹 추가 입력을 제공한다. 더보기는 PC·모바일 모두 푸터 우측 끝의 텍스트 없는 세로 점 세 개 아이콘으로 표시하며 Guide·Search·Bookmark·Settings를 제공한다. Escape는 더보기만 닫고 트리거로 포커스를 돌려준다.

2. 푸터 More의 Bookmark 명령은 그룹 사이드바를 유지하고 북마크 팝업을 연다. More 버튼에는 북마크 개수·상태 표시를 포함하지 않는다.

3. PC 푸터의 왼쪽에는 현재 그룹 이름을 푸터 명령 텍스트보다 2px 크게 표시하고, 클릭하면 그룹 메뉴를 열거나 열린 메뉴를 닫는다. 중앙 메뉴 버튼에는 가로 세 줄 메뉴 아이콘과 `Menu`(한국어 설정에서는 `메뉴`) 라벨을 표시한다. 모바일은 별도 왼쪽 그룹명을 숨기고 첫 번째 메뉴 버튼에 같은 가로 세 줄 메뉴 아이콘과 현재 그룹 이름을 표시한다.

4. Group 메뉴의 All Group·All My Group·All Shared Group·Ungrouped 항목에는 그룹 동작 아이콘을 표시하지 않는다.

5. PC에서 일반 그룹의 우측 동작 아이콘으로 연 드롭다운에는 Close All·공유·수정·삭제만 표시하고 Bookmark를 표시하지 않으며 그룹 선택을 바꾸지 않는다. 그룹명 우클릭은 `Pin to footer` 한 항목만 표시한다. 그룹 드롭다운은 최소 216px로 넓혀 텍스트가 잘리지 않으며 우측 점 세 개의 Edit로 기존 그룹명 수정 입력을 연다.

6. 오늘 생성되거나 변경된 그룹이 있으면 Group 아이콘에 Bookmark와 같은 붉은 점을 표시하고, 오래된 그룹만 있으면 표시하지 않는다.
