# PC 푸터 고정과 정렬

> E2E: `tests/05. 화면과 설정/35. PC 푸터 고정과 정렬/`

1. PC에서 개별 My/Shared 그룹명을 우클릭하면 `Pin to footer` 한 항목의 드롭다운을 표시한다. Pin to footer로 즉시 고정하며 이미 고정한 그룹은 해당 항목을 비활성화해 중복 추가하지 않는다. 푸터에서 우클릭해 고정을 해제한다. 기본 메뉴·대시보드·계정 3개는 순서를 바꿀 수 있지만 고정을 해제할 수 없다.

2. PC의 그룹 드롭다운(All Group·All My Group·All Shared Group·Ungrouped), 더보기 드롭다운(Guide·Search·Bookmark·Settings), 계정 드롭다운(Logout·My Page·Board)의 각 진입점은 모두 우클릭 `Pin to footer` 메뉴를 제공한다.

3. PC 푸터를 드래그할 때 대상 항목의 앞·뒤와 항목 사이 빈 공간에 맞춰 정확한 삽입선을 표시한다. 놓기 전에는 순서를 바꾸지 않으며 놓으면 표시한 위치로 이동한다. 드래그 종료 시 표시를 해제하고 새로고침 후 순서를 복원한다. 더보기는 정렬 대상에 포함하지 않고 우측 끝을 유지한다.
