# PC 푸터 고정과 정렬

> E2E: `tests/05. 화면과 설정/35. PC 푸터 고정과 정렬/`

1. PC에서 개별 My/Shared 그룹명을 우클릭하면 `Pin to footer` 한 항목의 드롭다운을 표시한다. Pin to footer로 즉시 고정하며 이미 고정한 그룹은 해당 항목을 비활성화해 중복 추가하지 않는다. 푸터에서 우클릭해 고정을 해제한다.

2. PC의 그룹 드롭다운(All Group·All My Group·All Shared Group·Ungrouped), Menu 드롭다운(Guide·Search·Bookmark·Settings·Board), 계정 드롭다운(Logout·My Page)의 각 진입점은 모두 우클릭 `Pin to footer` 메뉴를 제공한다.

3. PC 푸터를 드래그할 때 대상 항목의 앞·뒤와 항목 사이 빈 공간에 맞춰 정확한 삽입선을 표시한다. 놓기 전에는 순서를 바꾸지 않으며 놓으면 표시한 위치로 이동한다. 드래그 종료 시 표시를 해제하고 새로고침 후 순서를 복원한다. 더보기는 정렬 대상에 포함하지 않고 우측 끝을 유지한다.

4. PC 기본 Group·Card·계정도 우클릭 Unpin from footer로 해제하고 Menu 맨 아래로 옮긴다. 세 항목을 모두 해제하면 중앙을 비우며 새로고침 후에도 유지한다. Menu 항목 우클릭 Pin to footer로 다시 고정한다.
5. 해제한 Group·Card·계정은 Menu 하단에서 한 번 클릭해 사용할 수 있다. 이동한 계정의 키보드 탐색과 My Page 진입도 유지한다.
6. PC 고정을 모두 해제한 설정을 복원해도 모바일은 기본 그룹·카드·사용자·Menu 네 진입점을 유지한다. Menu에는 중복된 기본 항목을 표시하지 않으며 키보드 탐색도 숨겨진 항목을 건너뛴다.

7. 이전 서버 스냅샷에 푸터 고정 목록·아이콘 표시 설정이 없으면 저장된 로컬 설정을 유지한다. 명시적인 서버 설정은 기존 동기화 규칙을 따른다.
