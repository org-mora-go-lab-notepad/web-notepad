# PC 푸터 고정과 정렬

> E2E: `tests/05. 화면과 설정/35. PC 푸터 고정과 정렬/`

1. PC에서 개별 My/Shared 그룹명을 우클릭하면 단독 고정 메뉴 대신 `Close All → Pin to footer → Edit` 순서의 드롭다운을 표시한다. Pin to footer로 즉시 고정하며 이미 고정한 그룹은 해당 항목을 비활성화해 중복 추가하지 않는다. 고정 항목을 드래그해 순서를 바꾸고 새로고침 후 복원하며, 푸터에서 우클릭해 고정을 해제한다. 기본 메뉴·대시보드·계정 3개는 순서를 바꿀 수 있지만 고정을 해제할 수 없다.

2. PC의 그룹 드롭다운(All Group·All My Group·All Shared Group·Ungrouped), 더보기 드롭다운(Guide·Search·Bookmark·Settings), 계정 드롭다운(Logout·My Page·Board)의 각 진입점은 모두 우클릭 `Pin to footer` 메뉴를 제공한다.
