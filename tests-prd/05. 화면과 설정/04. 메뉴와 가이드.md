# 메뉴와 가이드

> E2E: `tests/05. 화면과 설정/04. 메뉴와 가이드/`

1. 하단 우측 계정 영역은 비로그인 시 로그인 아이콘과 Login을 중앙에 표시하고 로그인 후 프로필 이미지와 이름을 표시한다. 푸터 우측 Menu 메뉴에는 맨 위에 Theme를 표시하고 Guide·Search·Bookmark·Settings·Board 순서로 표시한다. Board는 계정 메뉴에서 제외한다.

2. PC User Guide의 첫 번째 1/11 `Keyboard shortcuts` 설명에 있는 `Shortcut` 진입점을 선택하면 기존 단축키 패널을 열고 가이드와 Menu 메뉴를 닫는다.

3. 푸터 우측 Menu의 `Guide`를 선택하면 `User Guide` 팝업을 첫 단계부터 연다. PC는 단축키 안내를 포함한 11단계다.

4. 푸터 Menu는 Theme를 맨 위에 두고 Guide·Search·Bookmark·Settings·Board 순서로 표시한다. Theme부터 Board까지 Tab으로 순서대로 탐색할 수 있다.

5. `Shortcut` 패널은 편집 실행 취소 `Cmd + Z`와 다시 실행 `Cmd + Shift + Z`를 안내한다. 한 동작에 단축키가 두 개 이상이면 설명 오른쪽에서 각 키 조합을 한 줄씩 세로로 쌓아 오른쪽 정렬하고, 설명은 첫 키 조합과 나란히 표시한다.

> 표시 규칙: 가이드 Previous·Next 버튼의 텍스트와 아이콘은 같은 세로 중심선에 정렬한다. 이 세부 정렬만을 위한 별도 E2E는 두지 않는다.

6.  사용 가이드 팝업은 Escape로 닫는다.

> 2단계 이상에서 닫은 사용 가이드를 다시 열면 1단계부터 표시한다.

> 사용자 가이드 팝업 바깥의 배경을 클릭하면 팝업을 닫는다.

> 사용 가이드 팝업을 처음 열면 `Next` 버튼에 포커스를 둔다.
