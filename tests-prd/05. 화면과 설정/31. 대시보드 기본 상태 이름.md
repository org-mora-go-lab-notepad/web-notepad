# 31. 대시보드 기본 상태 이름

> E2E: `tests/05. 화면과 설정/31. 대시보드 기본 상태 이름/`

1. 설정의 Delete all data 영역 위에서 To Do·Waiting·In Progress·Done·Closed의 기본 이름을 편집하고 저장한다. 일반 그룹과 All Group의 대시보드에 적용하며 새로고침 후에도 보존한다. 빈 이름은 언어별 원래 이름으로 표시하고 입력은 30자까지 허용한다.
2. 그룹의 Edit Status에서 지정한 이름은 설정의 기본 이름보다 우선하며, 기본 이름을 변경해도 그룹의 이름을 덮어쓰지 않는다.
3. 기본 이름 초기화는 다섯 상태의 원래 이름을 복원하고 그룹에서 따로 지정한 이름을 유지한다.
4. 로그인 사용자의 기본 이름 설정은 개인 이력에 저장하고 같은 계정의 다른 기기에서도 복원한다.
5. 기본 상태 이름을 수정하기 전에는 Save를 비활성화하고, 수정하면 활성화한다. 저장 직후 `Saved` 상태를 표시하고 Save를 다시 비활성화하며 실제 로컬 저장값과 새로고침한 입력값을 동일하게 복원한다.

6. 개별 그룹 Edit Status의 왼쪽 라벨은 Settings에서 저장한 기본 상태 이름을 표시하고 미지정 상태만 원래 이름을 사용한다. 오른쪽 입력 placeholder는 비워 두며 기존 그룹별 이름은 입력값으로 보존한다. 그룹 이름을 저장해도 기본 이름은 바뀌지 않는다.

7. 한국어 기본 상태 이름은 할 일·대기중·진행중·완료·종료 순서로 표시한다.
