# 설정 - 패널과 즉시 적용

> E2E: `tests/05. 화면과 설정/08. 설정 - 패널과 즉시 적용/`

1. Panel Slide 설정은 제공하지 않으며 PC·모바일의 모든 패널은 항상 슬라이드 애니메이션 없이 즉시 표시한다. 이전 On 저장값은 무시하고 기존 탭 데이터는 보존한다.

2. Tab Colors에서 순번의 색상을 바꾸면 열린 탭의 이전 색상을 같은 순번의 새 색상으로 바꾸고 대시보드의 To Do·Ready·Doing 상태를 유지한다.

3. Group Position 아래 Panel Position에서 Left·Right(한국어 왼쪽·오른쪽)를 선택한다. 기본값 Right이며 그룹 위치와 독립적으로 Card·Settings 등 사이드 패널 위치에 즉시 적용한다.

4. Group Position은 기본 Left이며 Right 선택을 브라우저에 저장하고 새로고침 후 그룹 패널을 선택한 가장자리에 복원한다. Panel Position 값은 바꾸지 않는다.

5. 탭 색상 순서를 초기화하면 열린 탭·북마크·닫은 탭 중 To Do·Ready·Doing의 색상을 같은 순번의 기본 색상으로 바꾸고 Note·Done과 대시보드 상태를 유지한다.

6. 선택한 폰트 비율은 탭·편집기·하단 메뉴·우측 패널에 즉시 적용한다. 탭 타이틀은 비율 적용 후 2px 줄이고 편집기는 2px 줄이며 PC 기본 90%에서 각각 11.5px·15.1px, 120%에서 16px·20.8px로 표시한다.

7. `Footer Icons Only` 설정은 PC 푸터의 아이콘만 표시하도록 On·Off로 전환하며 기본값은 Off다. 선택은 새로고침 뒤에도 유지하고 모바일 푸터의 텍스트는 숨기지 않는다.

8. PC의 Group Position과 Panel Position 좌우 네 조합에서 그룹은 선택한 화면 끝에 배치하고 그룹·고정 패널·메인 에디터는 서로 겹치지 않는다.
9. 오른쪽 그룹은 왼쪽 경계를 끌어 너비를 늘리며 위치·너비를 새로고침 후 복원한다. Group Option 드롭다운도 화면 안에 표시한다.
10. 모바일에서 Group Position을 Right로 선택해도 그룹 패널은 화면 너비를 채우고 푸터 위까지만 표시한다. 크기 조절 손잡이는 숨기고 첫 푸터 터치로 닫는다.
