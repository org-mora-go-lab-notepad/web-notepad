# 26. Turso 변경 이력

> E2E: `tests/05. 화면과 설정/26. Turso 변경 이력/`

1. 로그인 후 그룹과 글을 연속 변경하면 마지막 변경에서 0.25초 뒤 최신 이력을 저장한다. 저장 요청을 전송하는 동안 수정한 탭 상단 선에 왼쪽에서 오른쪽으로 흐르는 반짝임을 표시하고 대기 중과 완료 후에는 정지하며 우측 하단 상태 영역은 표시하지 않는다.
2. 노트 상태를 변경하면 Turso 이력의 스냅샷에 해당 상태를 저장한다.
3. 입력한 본문 저장이 실패해도 대기 중인 변경을 유지하고 자동 재시도하여 최신 이력에 같은 본문을 보존한다. 초기 빈 탭 준비 저장은 본문 변경의 실패·재시도 횟수와 구분한다.
4. 저장 전 새로고침해도 대기 중인 변경을 복구해 저장한다.
5. 움직임 줄이기 환경에서는 저장 중 탭 상단 선의 반짝임을 정지한다.
6. 탭 본문의 길이와 관계없이 빈 내용과 1~2자 내용도 DB 스냅샷에 보존하며, 본문 길이를 이유로 탭을 자동 삭제하지 않는다.
7. 탭 닫기는 에디터에서 숨기는 동작이며 저장 대기 중인 본문과 탭 ID를 DB에 보존한다. 새로고침 후에도 닫힌 상태와 본문을 복원하고 탭 닫기를 삭제 의도로 처리하지 않는다.
8. 로그인 사용자의 첫 진입은 최신 DB 동기화가 끝날 때까지 앱 상단에 80% 불투명도의 Done 색상 계열 슬라이드 진행 바를 고정 표시한다. 이때 화면을 가리는 skeleton과 문구는 표시하지 않고, 준비된 앱은 그대로 보이되 클릭·터치 입력을 차단한다.
