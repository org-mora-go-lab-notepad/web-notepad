# 19. 빈 탭 직접 닫기

> E2E: `tests/01. 앱 기반/19. 빈 탭 직접 닫기/`

본문을 모두 지워 빈 문자열이 된 탭을 사용자가 개별 닫기 버튼·가운데 클릭·닫기 단축키로 직접 닫을 때만 삭제한다. 공백도 내용으로 취급하며 1~2자 본문은 삭제 대상이 아니다. 빈 내용만 저장하거나 전체 닫기·그룹 이동을 실행하는 것은 삭제 동의가 아니다. 기존 DB의 그룹이나 빈 탭을 일괄 정리하지 않는다. 삭제는 해당 ID와 최신 저장 기준을 명시하고 기존 서버의 누락 방지와 삭제 직전 백업을 유지한다.

1. 개인 탭의 본문을 비운 직후 직접 닫으면 DB에서 해당 ID만 제거하며 다른 그룹과 두 글자 본문 탭은 그대로 보존하고 재접속해도 유지한다.
2. 공유 탭의 본문을 비운 직후 직접 닫으면 서버에서 해당 ID만 제거하며 마지막 탭을 대신 생성하지 않고 상단 새 탭 버튼만 제공하며 재접속 후 제거 상태를 유지한다.
3. 공백이나 두 글자라도 내용이 남아 있으면 직접 닫아도 원문과 탭 ID를 보존한다.
4. 공유 빈 탭을 직접 닫는 도중 다른 사용자의 수정과 충돌하면 클라이언트가 삭제 의도를 재사용하지 않고 서버 최신 원문을 복원하며 재접속 후에도 보존한다.
