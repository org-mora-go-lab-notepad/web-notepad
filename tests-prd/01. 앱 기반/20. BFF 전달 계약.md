# 20. BFF 전달 계약

> E2E: `tests/01. 앱 기반/20. BFF 전달 계약/`

1. 외부 Origin의 인증된 저장 요청은 BFF에서도 거부된다.
2. 개인 저장 결과와 캐시 정책을 BFF에서 그대로 전달한다.
3. BFF는 클라이언트의 위조 사용자·게이트웨이 헤더를 신뢰하지 않고 카카오 세션으로 발급한 단기 토큰의 사용자만 사용한다.
4. 공유 링크는 BFF 호스트가 아닌 현재 프런트 주소를 유지하며 카카오 로그인 복귀 쿠키에서도 유효하다.
5. 기존 키의 버전 없는 공유 링크와 로그인 세션을 BFF 연결 후에도 유지한다. 신규 공유 및 게시판 URL은 BFF 전용 키로 서명하며 기존 키의 링크도 카카오 세션 인증 경계에서 검증해 계속 사용할 수 있다.
6. 클라이언트가 위조한 공유 검증 헤더로 잘못된 링크에 참여할 수 없으며 기존 그룹 본문은 보존한다.
7. 기존 사용자 ID별 개인 그룹과 본문은 BFF 연동 후에도 다른 계정으로 섞이지 않는다.

8. 프런트의 `app/api`에는 카카오 인증 및 세션 토큰 발급만 두며 그룹·게시판·이력 경로는 404를 반환한다.

9. 게시판 화면은 브라우저에서 BFF origin으로 직접 GET 요청을 보내고 프런트 업무 API 경로를 사용하지 않는다.
