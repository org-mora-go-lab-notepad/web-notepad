# 20. BFF 전달 계약

> E2E: `tests/01. 앱 기반/20. BFF 전달 계약/`

1. 외부 Origin의 인증된 저장 요청은 BFF에서도 거부된다.
2. 개인 저장 결과와 캐시 정책을 BFF에서 그대로 전달한다.
3. 프런트는 클라이언트의 위조 BFF 헤더를 신뢰하지 않는다.
4. 공유 링크는 BFF 호스트가 아닌 현재 프런트 주소를 유지하며 카카오 로그인 복귀 쿠키에서도 유효하다.
5. 기존 키의 버전 없는 공유 링크와 로그인 세션을 BFF 연결 후에도 유지한다. 공유 및 게시판 URL은 프런트에서 기존 키로 서명한다.
6. 클라이언트가 위조한 공유 검증 헤더로 잘못된 링크에 참여할 수 없으며 기존 그룹 본문은 보존한다.
7. 기존 사용자 ID별 개인 그룹과 본문은 BFF 연동 후에도 다른 계정으로 섞이지 않는다.
