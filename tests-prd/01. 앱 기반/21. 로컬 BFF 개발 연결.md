# 21. 로컬 BFF 개발 연결

> E2E: `tests/01. 앱 기반/21. 로컬 BFF 개발 연결/`

1. 기본 개발 실행기는 web-notepad-bff 저장소 없이 프런트 3000과 독립 Mock API 3001을 실행한다. 실제 BFF는 --bff 또는 dev:bff로 명시했을 때만 탐색하고 연결한다.
2. 실제 BFF 모드에서 BFF 경로가 잘못되면 서버 시작 전에 명확한 오류로 중단한다.
3. 프런트 Swagger에서 카카오 세션에서 발급받은 단기 Bearer 토큰으로 BFF의 개인 이력을 직접 조회한다.
4. 프런트 Swagger 명세는 BFF 직접 호출 토큰 계약을 제공하며 비로그인 API 접근을 허용하지 않는다.

5. 독립 Mock API는 사용자별 CRUD 상태를 로컬 JSON에 영구 저장하고 재시작 후 원문을 복원한다. Turso 환경 변수가 존재해도 DB에 연결하지 않는다. 테스트는 격리된 메모리·임시 JSON 파일만 사용한다.
