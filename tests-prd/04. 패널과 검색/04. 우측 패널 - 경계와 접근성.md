# 우측 패널 - 경계와 접근성

> E2E: `tests/04. 패널과 검색/04. 우측 패널 - 경계와 접근성/`

1.  모바일 오버레이 패널 경계 바깥 11.52px에 Dark 16%·Light 22% 경계색의 다단계 그라데이션을 표시한다.

2.  경계 음영은 포인터 이벤트를 받지 않아 카드 클릭과 패널 크기 조절을 막지 않는다.

3.  PC에서 패널 바깥을 클릭해도 고정 패널을 유지한다.

4.  고정 중에는 배경 덮개와 그림자·경계 그라데이션을 표시하지 않아 편집기를 계속 사용할 수 있다.

5.  X로 패널을 닫으면 PC의 패널 진입 버튼 포커스를 해제한다.

6.  하단 패널 버튼은 X로 닫은 뒤에도 그룹·대시보드 순서의 Tab 탐색에서 정상 포커스를 표시하고, 열린 패널의 아이콘 버튼도 키보드 포커스를 2px 외곽선으로 명확히 표시한다.

7.  PC 탭 영역과 좌우 패널의 제목·닫기 버튼 영역은 모두 44px 높이를 사용해 본문 시작선을 일치시킨다. 모바일 헤더 크기는 유지한다.

8.  PC 그룹·카드 헤더의 아이콘 버튼은 기본·메뉴 열림 상태에서 테두리를 숨기고 hover에서만 표시한다. hover 전후 크기와 위치는 유지하고 키보드 포커스 윤곽선은 제공한다.
