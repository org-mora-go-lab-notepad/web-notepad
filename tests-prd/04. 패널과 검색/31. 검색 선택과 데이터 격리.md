# 31. 검색 선택과 데이터 격리

> E2E: `tests/04. 패널과 검색/31. 검색 선택과 데이터 격리/`

1. 서로 다른 그룹의 같은 제목 탭을 구분하고 선택한 그룹의 원문을 연다.

2. 다른 그룹의 탭을 검색만 해서는 활성 그룹과 편집 탭을 변경하지 않는다.

3. 원본 없는 북마크는 검색 결과에 포함하지 않으며 탭을 자동 복원하거나 북마크 원문을 제거하지 않는다.

4. 새 검색어의 탭 결과로 이전 결과를 교체하며 별도 미리보기를 표시하지 않는다.

5. 검색어를 본문으로 좁히면 일치하는 탭 원문과 하이라이트를 유지한다.

6. 검색 팝업을 닫았다 다시 열면 검색어와 탭 결과는 유지하되 결과를 자동으로 열지 않는다.
