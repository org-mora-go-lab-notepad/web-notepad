# 06. 검색 - 전체 검색

> E2E: `tests/04. 패널과 검색/06. 검색 - 전체 검색/`

1. 푸터 More의 Search를 선택하면 raised 배경·얇은 테두리의 검색 모달을 연다. 헤더에는 검색 진입점을 표시하지 않고 사이드바 열림 상태를 유지한다.

2. 검색어가 없으면 Enter a search term을 표시한다.

3. 탭 검색 결과가 없으면 No search results를 표시한다.

4. 입력이 멈춘 뒤 0.3초가 지나면 탭 제목·본문만 대소문자 구분 없이 부분 검색한다. 입력 중에는 기존 결과를 유지하며 그룹·북마크 결과를 만들지 않는다.

5. 탭 검색 결과를 선택하면 해당 그룹의 탭을 편집기에 열고 검색 팝업을 닫는다.

6. 결과는 Groups·Tabs 구분 헤더나 별도 미리보기 없이 탭 목록 한 열로 표시한다. 검색 입력과 목록 너비를 맞추고 목록 스크롤 시 검색창 바로 아래 그라데이션을 표시한다.

7. PC·모바일 검색 카드 본문은 Enter와 빈 줄을 보존하고 최대 여섯 줄로 표시한다. 나머지 원문은 DOM에 유지하고 검색어를 하이라이트한다.
