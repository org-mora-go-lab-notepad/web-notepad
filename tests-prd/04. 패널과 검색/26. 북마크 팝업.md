# 26. 북마크 팝업

> E2E: `tests/04. 패널과 검색/26. 북마크 팝업/`

1. 검색과 북마크는 최대 너비 655.2px의 모달로 표시한다. 북마크 높이는 540.8px, 검색은 PC 540.8px·모바일 648.96px(20% 증가)이며 화면 높이에 맞춰 제한한다. 중앙보다 80px 위에 표시하되 상단 36px 안쪽으로 제한한다. 배경을 어둡게 덮고 작업 영역 너비는 유지하며 패널 고정·크기 조절 버튼을 제공하지 않는다.
2. 고정 대시보드가 열려 있어도 북마크는 화면 중앙보다 80px 위에 표시하고 대시보드와 작업 영역 너비를 유지한다.
3. Escape로 북마크 팝업을 닫으면 하단 Group 버튼으로 포커스를 돌린다.
4. 모달 배경을 클릭하면 북마크를 닫고 편집기를 계속 사용할 수 있다.
5. 대시보드가 열려 있어도 PC 검색과 북마크 모달은 같은 크기와 위치를 유지한다. 창과 작업 영역의 너비가 변경되어도 두 모달의 크기와 위쪽 배치를 일치시킨다.
6. More의 Bookmark 팝업에는 활성 그룹과 관계없이 모든 그룹의 북마크 제목·내용·그룹명을 표시한다. 북마크 카드는 본문을 최대 6줄로 표시하고 제목·그룹·삭제 버튼을 포함한 전체 높이는 내용에 맞춘다. 제목·그룹·본문의 글자 크기·글꼴·색상·줄 높이를 대시보드 탭 카드와 동일하게 사용한다.
