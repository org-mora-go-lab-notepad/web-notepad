# 30. 검색 문자열과 안전한 미리보기

> E2E: `tests/04. 패널과 검색/30. 검색 문자열과 안전한 미리보기/`

1. 정규식 특수문자가 포함된 검색어는 탭에서 리터럴 부분 문자열로 검색하고 강조한다.

2. 한글 검색어로 탭 본문을 찾고 원문을 편집기에 연다.

3. 검색어 앞뒤 공백을 제외하고 탭을 검색하되 입력값 자체는 유지한다.

4. 북마크한 탭도 중복 없이 탭 결과로 한 번만 표시하고 그룹·북마크 구분 영역은 만들지 않는다.

5. HTML 형태의 탭 본문은 검색 결과에서 실행하지 않고 텍스트로 표시한다.

6. 그룹명과 북마크에만 일치하는 검색어는 탭 결과를 만들지 않고 기존 데이터를 보존한다.
